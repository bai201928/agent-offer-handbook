## 教材目录

- [Java 核心、集合、并发、JVM 与 Spring：初学者到大厂高薪岗位教材](docs/java-core-spring/README.md)

## 教材原则

- 从初学者术语与工程直觉开始；
- 以真实可信的故障链组织知识，不堆砌孤立八股；
- 每道题提供 2～3 分钟主体回答、事故反例、企业级改进与递进追问；
- 技术版本与事实以官方文档为准；
- 项目案例用于教学，不虚构生产经历。

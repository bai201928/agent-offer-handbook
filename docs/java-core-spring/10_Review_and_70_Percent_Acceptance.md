## 一、为什么验收线是 51 道

本教材共 72 道题。51 / 72 = 70.8%。  
只要初学者能不看答案、独立回答下面 51 道主线题，就已经覆盖大多数 Java 后端一面、二面常见主线；其余 21 道用于高薪岗位深挖和项目加分。

## 三、单题 2～3 分钟口述结构

不要从定义开始背诵，统一按五段回答：

```text
1. 一句话结论：它解决什么问题，有什么边界
2. 初学者画面：用一个对象/线程/请求说明
3. 底层机制：按执行顺序说 3～5 步
4. 项目落地：在 Agent + RAG 平台哪里使用
5. 故障与取舍：错误会怎样，如何监控验证
```

### 示例骨架

> 结论上，ThreadLocal 是线程级变量隔离，不是全局缓存。底层值保存在每个 Thread 的 ThreadLocalMap 中……在项目里我用它保存 Trace 和租户上下文，但在线程池里必须 finally remove……跨线程任务会显式传递上下文，而不是依赖线程恰好相同。

## 四、三轮复习法

### 第一轮：建立画面

目标不是背答案，而是能画出四张图：

1. Java 源码到 JVM 执行图；
2. HashMap 与 ConcurrentHashMap 数据结构图；
3. 线程池提交、JMM 与锁关系图；
4. Spring 请求、事务与 Bean 代理图。

### 第二轮：事故推演

对每章至少回答：

- 如果线程在这个位置宕机，会怎样？
- 如果两个请求同时进入，会争抢什么？
- 如果对象一直被引用，GC 为什么不能回收？
- 如果调用没有经过代理，事务为什么失效？
- 如果队列无界，压力最终转移到哪里？

### 第三轮：项目深挖

围绕 Agent 项目做 30 分钟模拟面试：

```text
HTTP 请求如何建立租户和 Trace？
为什么不用一个全局线程池？
RAG 和画像怎样并行？
虚拟线程为什么仍需要连接池和 Semaphore？
AgentRun 与 Outbox 为什么在同一事务？
模型调用为什么不能放长事务？
ThreadLocal 怎样清理和传播？
会话缓存 OOM 如何分析？
事务失效如何证明是 self-invocation？
Spring Boot 自动配置为什么会 back off？
```

## 五、评分标准

每题 10 分：

| 维度 | 分值 | 合格表现 |
|---|---:|---|
| 结论与边界 | 2 | 不说绝对化结论 |
| 基础解释 | 2 | 初学者能听懂 |
| 运行机制 | 2 | 能按时间顺序讲 |
| 项目落地 | 2 | 能联系真实组件 |
| 故障与验证 | 2 | 能说指标、工具或测试 |

- 7 分：达到大厂常规岗位合格线；
- 8 分：回答有工程取舍；
- 9～10 分：能处理追问、故障与版本差异。

# 第七部分：36 题复习地图、70% 验收与常见错误校正

## 1. 为什么保留这 36 题

主线题必须同时满足：能解释真实请求、影响线上正确性或性能、大厂高频、能连接 Java/Agent 项目、可以追问失败窗口和监控。

不单独占用题号：函数清单、冷门类型上限、纯手写 SQL 算法题、只背三大范式、MyISAM 冷门细节、源码行号和没有项目落点的参数枚举。

## 5. 初学者最容易说错的 18 句话

### 1. MySQL 就是 InnoDB

正确：Server 负责连接、解析、优化、执行框架和 Binlog；InnoDB 负责页、索引、事务、锁、Redo、Undo 和恢复。

### 2. 有索引就一定使用索引

正确：索引只是候选路径，优化器比较扫描、回表、排序、Join 等总成本。

### 3. 区分度最高的列必须放联合索引最前

正确：联合索引从等值、范围、排序、分页、投影和租户边界共同推导。

### 4. 范围条件后的列完全没用

正确：后续列通常不能继续缩小同一搜索边界，但仍可能参与过滤、覆盖或排序。

### 5. `Using index` 就一定快

正确：覆盖索引避免回表，但扫描百万条覆盖记录仍然慢。

### 6. 连接池越大吞吐越高

正确：资源饱和后，更多连接只把排队推进数据库内部。

### 7. Buffer Pool 命中率高就不会慢

正确：锁等待、宽扫描、排序、刷盘、大结果和客户端等待仍会导致高延迟。

### 8. InnoDB 行锁多了会常规升级成表锁

正确：InnoDB 不采用常规行锁自动升级。缺索引可能扫描并锁住大量记录，看起来像整表被锁，但概念不同。

### 9. 普通 SELECT 会给结果行加排他锁

正确：普通一致性读通常通过 MVCC 读版本；`FOR UPDATE`、`FOR SHARE` 和修改语句属于当前读。

### 10. RR 只靠 MVCC 解决所有幻读

正确：快照读依赖 Read View；范围当前读还会使用 Record、Gap 和 Next-Key Lock。

### 11. 死锁只能增加超时时间

正确：InnoDB 检测等待环并回滚一个事务；工程上应统一顺序、缩短事务、补索引并有限重试。

### 12. Redo、Undo、Binlog 是同一种日志

正确：Undo 回滚与 MVCC；Redo 崩溃恢复；Binlog 复制、CDC 和增量恢复。

### 13. Redo/Binlog 两阶段提交能保证 MySQL 与 RocketMQ 全局事务

正确：它只协调 MySQL 内部 Redo 与 Binlog；跨系统需 Outbox、幂等、Saga 和对账。

### 14. 主从复制意味着副本一定最新

正确：复制和应用存在延迟；读己之写要回主、粘主、等待 GTID 或检查业务版本。

### 15. 半同步复制等于零数据丢失

正确：半同步加强返回前确认，但确认点、网络分区和故障切换仍需明确。

### 16. 表大了就分库分表

正确：先治理 SQL、索引、冷热数据、归档、硬件和读扩展，再根据容量与写吞吐证据分片。

### 17. 分区表就是分库分表

正确：分区仍在一个实例；分片把数据路由到多个实例。

### 18. `@Transactional` 写在方法上一定生效

正确：它依赖代理调用，还受自调用、异常、传播、异步线程和数据源影响。

## 6. 最终六张图

### 请求图

```text
Java → 连接池 → JDBC → Server → Optimizer → Handler → InnoDB → 结果
```

### 索引图

```text
联合条件 → B+树范围 → 二级记录 → 必要时回表 → 返回
```

### 并发图

```text
Read View 决定看哪个版本
当前读决定锁哪个范围
条件 UPDATE / version 决定谁修改成功
```

### 提交恢复图

```text
Undo 支持回滚
Redo 支持崩溃恢复
Binlog 支持复制和增量恢复
提交协议协调 Redo 与 Binlog
```

### 高可用图

```text
主库提交 → Binlog → 副本重放
故障 → 隔离旧主 → 选最完整副本 → 切流 → 对账
```

### Agent 正确性图

```text
租户条件
+ 唯一约束
+ 状态机条件更新
+ version
+ tool_operation 幂等
+ Outbox
+ 故障恢复与审计
```

## 7. 面试最后不要只说方案名

低分回答：加索引、加锁、开事务、读从库、分库分表、加连接。

高分回答必须继续说明：

```text
为什么能解决？
会增加什么成本？
失败窗口在哪里？
数据事实由谁裁决？
怎样监控和压测？
怎样回滚？
```
